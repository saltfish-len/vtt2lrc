# <img src="docs/images/cover.png" width="50" /> VTT to LRC Converter for Android

一个简单、高效、隐私安全的 Android 本地工具，用于将 WebVTT (`.vtt`) 字幕文件批量转换为 LRC (`.lrc`) 歌词文件。

专为 Android 现代系统设计，支持**文件夹批量操作**与**原地转换**。

可在release处下载：
https://github.com/saltfish-len/vtt2lrc/releases
选择Assets中的app-release.apk

# Experimental Branch

本分支（`experimental`）为实验性开发分支，用于验证基于 FFmpeg 的音频处理能力，不作为正式功能或发布版本使用。

本分支的 `applicationId` 为 `com.saltfishlen.vtt2lrc.exp`，与正式版（`com.saltfishlen.vtt2lrc`）不同，
两者可以同时装在一台手机上，互不覆盖。启动器中显示为「VTT原地转换 实验版」。

## ✨ 功能特点 (Overview)

* **📂 批量原地转换**：利用 Android SAF (Storage Access Framework) 机制，用户授权整个文件夹后，App 会自动扫描并转换所有 VTT 文件，直接在**同一目录**下生成 LRC 文件，无需手动导入导出。
* **⚡ 极速处理**：基于 Kotlin 协程开发，文件读写与正则解析在后台线程瞬间完成，支持处理大量文件。
* **🧹 智能文件名整理**：支持去除嵌套扩展名。
    * 示例：`song.mp3.vtt` -> `song.lrc` (而非 `song.mp3.lrc`)。
* **🔒 隐私安全**：纯本地运行，不消耗流量，不上传任何文件至服务器。
* **📝 完美编码支持**：强制使用 UTF-8 编码读写，完美支持中文、日文及特殊符号，杜绝乱码。
* **🛠️ 高鲁棒性**：采用双侧锚定的正则匹配算法，精准提取时间轴与歌词文本。
* **📊 看得懂的进度**：处理中显示进度环与「正在处理第 N 个，共 M 个」；出错时给出原因和对应的处理方法，详细过程记录默认折叠。
* **🌗 跟随系统深色模式**：Material 3 配色，明暗两套主题。

## 🎵 本分支特有：视频提取音频

基于 FFmpeg，把视频里的声音提取成 MP3，存放在源文件夹中。

* **支持的格式**：MP4、MKV、MOV、AVI、FLV、WEBM、M4V、WAV，可多选。
* **两档音质**：高音质（VBR q=2）与省空间（CBR 192k）。
* **两种模式**：整个文件夹批量提取，或只处理单个文件。
* **WAV 转换后可选删除源文件**（默认关闭，删除不可撤销）。

> 单个文件模式依赖从文件路径反推输出目录，在部分设备上会失败。此时改用文件夹模式即可。

## 🚀 使用方法 (Usage)

1.  **准备文件**：将你的 `.vtt` 字幕文件放进手机上任意一个**你自己建的文件夹**里。系统不允许 App 访问「内部存储」根目录，以及「下载」和「Android」文件夹，选中它们时文件选择器上方会显示一行灰色提示。
2.  **选择模式**：打开 App，在「字幕」页根据需要开启或关闭「自动整理文件名」。
3.  **授权目录**：
    * 点击「选择文件夹，开始转换」按钮。
    * 在弹出的系统文件选择器中，找到你存放 VTT 的文件夹。
    * 点击底部的 **「使用此文件夹」(Use this folder)** 并点击 **「允许」(Allow)**。
4.  **等待完成**：转换过程中显示进度与当前文件名，完成后 `.lrc` 文件将直接出现在源文件夹中。如果有文件没转成功，界面会列出原因和处理方法。

提取音频则切到底部的「音频」页，勾好格式和音质后点「选择文件夹，批量提取」，流程与上面一致。

> 扫描不会进入子文件夹。如果文件分散在多级目录里，需要逐个目录选择。

## ⚠️ 注意事项 (Important Notes)

**关于数据覆盖（Overwrite Warning）：**

本应用采用**原地写入**策略，逻辑如下：
1.  扫描 `.vtt` 文件。
2.  计算目标 `.lrc` 文件名。
3.  **如果同名 `.lrc` 文件已存在，程序将直接覆盖旧文件**（实际上是先删除旧文件再写入新文件，以防止某些系统自动重命名为 `xxx (1).lrc`）。

> **建议**：在对重要数据进行批量操作前，请确保源文件夹中没有同名的重要 `.lrc` 文件，或已做好备份。
